# 用户号管理频道同步

入口：桌面管理端 → 频道管理 → 我的频道 → 同步账号频道。

1. 选择一个账号或全部已启用账号，点击“同步管理关系”。使用账号池里现有的在线 Telethon 客户端，不新建 session、不重复登录。
2. 完整读取会话列表，包含归档会话；只保留用户号为创建者或管理员的广播频道。普通成员频道、群组和机器人不导入。
3. 同一频道按 Telegram 数字 ID 合并，保留每个系统账号自己的身份、权限和检测时间。私密频道不要求用户名。
4. 同步不会自动加入“我的频道”，选择需要的频道后点击“导入所选频道”。已有频道保持原分组、备注、状态和 Bot 配置；新频道为“待检测”，绑定并检测 Bot 后才能作为正常目标频道使用。
5. 列表的“管理账号 / 身份”可点击查看权限；可按账号及创建者／管理员筛选，两项条件必须匹配同一账号。

## 状态与隔离

- 查询、同步、导入均以当前后台用户为归属人，管理员也不会扫描其他用户的 Telegram 账号。
- 新增 `account_channel_syncs` 和 `account_managed_channels` 两张表，并接入现有租户归属保护。
- 同步成功后按完整快照更新身份。已不再管理的频道只停用关系记录，不删除“我的频道”或旧记录。
- 离线、停用、超时、限流或同步失败保留上次结果，显示“未确认”。成功结果超过 24 小时也需重新同步，界面始终标注同步时间。
- 一次仅同步一个账号，同一账号不可重入；每次最长 45 秒。全账号同步逐个处理，显示进度和每个账号错误。
- 导入仅接受当前用户的有效同步结果，每次最多 200 个，重复导入不重复建频道。频道用户名对应的数字 ID 冲突时拒绝导入，要求先核对。
- 用户号管理权限和 Bot 发帖权限独立，整个功能不调用加入频道、邀请、授权或发送消息接口。

## 数据库迁移

服务启动时 `init_db()` 自动执行幂等迁移。在已有 SQLite 数据库上先使用 SQLite backup API 生成一致性备份，再创建新表；不修改旧表或重新分配归属人。

需要手动迁移时，在实际后端工作目录和同样的 `DATABASE_URL` 环境下运行：

```powershell
..\.venv\Scripts\python.exe migrate_managed_channels.py
```

随后重启后端并构建桌面前端。未涉及移动端或新增依赖。
