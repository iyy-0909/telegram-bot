# 请求按钮加载与防重复操作验收

日期：2026-09-22。

## 修改结果

桌面端 `admin/`、移动端 `admin-mobile/` 的请求按钮统一使用 `RequestButton`。操作同步上锁，异步期间显示 loading 并禁用，成功、异常或取消后自动释放。原有业务权限和禁用条件继续生效。

覆盖登录、验证码刷新、页面刷新、任务控制、表单保存、账号、Bot、频道、搜索机器人、客服、通知、告警和设置页面。纯本地操作保持同步。两端发请求的状态开关使用 `RequestSwitch`，在更新模型值之前拦截连续操作。

子组件经 `requestActions` 回调返回父组件请求的 Promise，解决普通 Vue `emit()` 无法等待父页面操作完成的问题。表单提交等待校验、请求和后续刷新；登录和通用规则编辑还在首次 await 前设置状态，防止回车提交绕过按钮。

主要文件：

- `frontend-shared/requestActions.mjs`、`requestButton.css`：共享控件及并发保护。
- 两端 `src/main.js`：控件注册。
- 两端 `App.vue`、组件和桌面布局：请求回调接入、补齐 Promise 返回。
- `admin/tests/request-actions.test.mjs`：10 个交互与并发测试。
- 两端 Dockerfile：复制共用模块；移动端独立构建使用仓库根目录作为上下文。

未增加依赖；按钮改动不涉及数据库结构。本次发布另包含监听补齐间隔设置，见 `docs/listener-catchup-interval.md`。

## 部署命令

将代码同步到服务器后，在仓库根目录执行：

```sh
docker compose up -d --build admin
```

以上为前端单独更新的命令。本次完整发布需同时构建后端，并以实际发布记录为准。新增按钮的使用规范见 `frontend-shared/README.md`。
